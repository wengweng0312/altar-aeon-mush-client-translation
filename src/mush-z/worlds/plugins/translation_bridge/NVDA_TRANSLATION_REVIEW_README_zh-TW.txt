Mush Client Translation Review NVDA add-on v17

用途：
保留既有 Mush Client 無障礙支援，並在 Translation Mode 的「中文檢閱模式」中改用：

小鍵盤 7：上一筆翻譯紀錄
小鍵盤 9：下一筆翻譯紀錄
Shift+小鍵盤 7：第一筆翻譯紀錄
Shift+小鍵盤 9：最後一筆翻譯紀錄

選到一筆翻譯紀錄後，NVDA 原生文字檢閱可直接操作該筆中英文字：
英文原文會合併成一行放在最上方；中文標題與句子拆行放在下方。檢閱游標預設位於最下方中文行，方便由下往上閱讀。
多句房間會在 history 顯示層展開成真正的多筆紀錄：英文合併成一行放在上方，中文標題與中文句子各自一行放在下方。小鍵盤 7／9 每次移動一行，可以越過整個房間繼續進入上一個或下一個房間，不會被限制在單一房間內。原 Ctrl+Shift+PageUp／PageDown 的舊式整筆朗讀保持不變。
所有普通翻譯都使用相同的真正 history 行規則：完整英文合併成一行在上，中文在下。即使只有一句，也會建立英文、中文兩行，確保小鍵盤 7／9 一定能走到原文。跨行 NPC 對話則保留為一行完整英文與一行完整中文，不依標點拆碎。
Quest 會使用既有結構分類：英文任務名稱、地點、等級、概述與各目標逐類排列在上方；對應的中文分類完整排列在下方。由底部往上閱讀時先讀中文，再逐類查閱英文，不會把整份英文黏成一行。
`skills <職業>` 的職業技能表使用結構化逐列顯示：每一列英文技能的下方緊接對應中文列，方便由下往上先讀中文、再查看該項英文。等級、練習、百分比、順序與依賴關係不得合併或遺失。
小鍵盤 7／9 不再固定等待 80 ms；add-on 會立即偵測檢閱檔更新，穩定 5 ms 後處理，慢速檔案系統才繼續等待，安全上限約 120 ms。
Scan 結果由 Translation Mode 以每個方向一行寫入 history，因此可直接用小鍵盤 7／9 逐方向巡覽。
使用小鍵盤 7 離開最新紀錄後，新訊息只會追加，選取位置保持不動；回到最底部後才恢復跟隨最新訊息。`某人 says, '...'` 等跨行引號對話會合併為一筆，不套用房間句子拆行規則。
小鍵盤 4／6：先按中文完整句子瀏覽，再接著按英文單字瀏覽
小鍵盤 1／3：上一個／下一個字元
小鍵盤 5／2／8：目前單字／字元／整行
Shift+小鍵盤 1／3：行首／行尾，並與小鍵盤 4／6 共用同一個檢閱位置

Help 原文會依頁碼、Keywords、Skill／Spell、Usage、指令及完整段落分行；房間原文仍維持單行置頂。

Translation Mode 關閉時，上述按鍵維持 NVDA 原生文字檢閱功能。
狀態檔遺失、過期或格式錯誤時，也會自動退回 NVDA 原生功能。

安裝：
1. 執行 Mush_Client_Translation_Review_v3.nvda-addon。
2. 依 NVDA 提示完成安裝並重新啟動 NVDA。
3. 在 Mush-Z 以 Ctrl+Shift+T 切換兩種模式：中文檢閱、關閉。

移除：
使用 NVDA 的附加元件商店移除「Mush Client」。若需回到舊版，重新安裝原本的 Mush Client add-on v2。

注意：
這是既有 Mush Client add-on v2 的相容合併版，不是第二個互相衝突的 mushclient App Module。
